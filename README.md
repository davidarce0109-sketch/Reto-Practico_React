## 🚀 Descripción General
Aplicación web frontend interactiva de comercio electrónico para la **TIENDA PALMIRA**, desarrollada con React y Vite. Incluye gestión completa de estado de carrito, validación estricta de entradas numéricas, prevención de sobre stock, confirmaciones modales para eliminación de productos mediante sistema de Toasts propio (sin librerías externas) y persistencia en `localStorage`.
